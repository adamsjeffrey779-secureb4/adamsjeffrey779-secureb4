## 📂 Projects

### 🛡️ RADAR — Real-Time Detection Across Email & IoT Line of Conmmunication 
*(Final Year Project — University of Mines and Technology, Ghana)*

A centralised multi-vector threat detection framework that simultaneously monitors and protects both email inboxes and IoT devices under a single administration, with cross-domain correlation to detect multi-stage attacks.

**Email Security — 9 Rule-Based Security Layers:**
- Phishing detection with AI-powered reasoning
- Business Email Compromise (BEC) detection
- Lookalike domain detection — flags sender domains imitating your organization's domain
- Dangerous attachment detection — extension mismatch, double-extension tricks (e.g. invoice.pdf.exe), macro-enabled Office files
- High-frequency sender detection
- Suspicious keyword detection
- And more advanced rule-based layers

**IoT Security — 5 Common Attack Vectors Monitored:**
- Unauthorized command injection
- Credential theft & default credentials
- Anomalous traffic detection
- Fake firmware detection
- Unauthorized source detection

**Cross-Domain Correlation Engine:**
RADAR watches both email and IoT activity simultaneously and correlates events across both to detect multi-stage attacks — recognizing that attackers often use email as the entry point before moving laterally through IoT devices connected to an organization's network or cloud.

**AI Reasoning Layer:**
The Anthropic Claude API powers RADAR's reasoning layer — handling novel phishing attempts that require human-like reasoning. Claude provides plain-language explanations of why a message was flagged, making threat findings accessible to non-technical users.

**Built with:** Next.js, Node-RED
**Future Plans:** Integrating machine learning for dynamic and adaptive threat detection across both email and IoT vectors.
